【OI 工具箱】快速上手　v1.11

一、界面
  无边框 macOS 风格窗口：
  · 左上角三个圆点是「红绿灯」：红=关闭、黄=最小化、绿=最大化
    鼠标悬停在三个点上才会显示 × − + 符号（和 macOS 一致）
  · 按住顶部空白处可以拖动窗口；窗口四边和四角可以拉伸改变大小
  · 左侧彩色图标是导航：窗口 / 背景 / 音乐 / 被控提醒 / 竞赛环境 / 通用
  · 右侧内容区是分组卡片，超出部分用鼠标滚轮上下滚动
  · 操作结果以顶部滑入的浮动提示条反馈，点一下提示条可以立刻收起

二、启动与退出
  双击 WindowTool.exe 默认直接显示主界面。
  · 「通用 → 静默启动」勾选后，以后双击只在右下角托盘出现图标(不弹窗口)
  · 「通用 → 开机自动运行」= 随 Windows 登录自动运行(写入当前用户注册表 Run 项)
  · 单击托盘图标 = 打开主界面；右键托盘图标 = 弹小菜单
  · 点小窗口的 × 只是隐藏到托盘，不影响正在生效的功能
  · 托盘菜单里选「退出」才会彻底关闭，并自动还原所有被修改的窗口

三、窗口管理（第 1 页）
  1. 在「目标窗口」列表里点选，或按「点选窗口」后直接去点目标窗口（Esc 取消）
  2. 列表上方可以输入关键词实时过滤，匹配标题、进程名和窗口类名
  3. 每行右侧会标出该窗口的当前状态：置顶 / 穿透置顶 / 有背景
  4. 「始终置顶」和「点击穿透」是开关：穿透置顶会同时置顶并把透明度设为 245
     多个窗口都开了穿透置顶时，先开启的始终压在后开启的上面
  5. 「窗口透明度」滑块即时生效，每个窗口独立记忆，切换选中窗口时自动跟随
  6. 「层级调整」只在同一层级带内上下移动，不会误跨越置顶层；「移到最底」把窗口压到最下面
  7. 「还原全部穿透置顶」一次性取消本工具做过的全部 ② 操作

四、窗口背景（第 2 页）
  · 图片背景：目标窗口变半透明，背景图窗口紧贴其下方实时跟随移动
  · 视频背景：选一个视频无限循环播放；或「加载视频文件夹」把整个目录做成轮播列表
    列表里双击某一条即可切换，也可以用上/下一条、随机切换（Ctrl+Alt+R）
  · 显示模式：
      填充裁剪 = 等比放大铺满窗口，居中裁掉超出部分（推荐，无黑边不变形）
      完整显示 = 等比缩放到完全可见，不足处显示黑边
      变形铺满 = 强行拉伸到窗口大小（可能变形）
  · 背景态透明度：数值越低越能看清被背景挡住的窗口内容
  · 定时自动切换：填分和秒，两项都为 0 表示关闭
  · 记住各窗口背景：关闭程序时记住哪些窗口用了什么背景、各自的透明度与显示模式；
    下次启动后若出现同名进程且同标题的窗口，会在约 2 分钟内自动恢复

五、音乐与歌词（第 3 页）
  · 曲目列表：在「本地歌库」和「网易云搜索」之间切换
  · 本地歌库：点「扫描本地曲库」，会扫描网易云下载目录(CloudMusic)、酷狗目录和系统音乐库；
    也可以「导入文件夹」临时加入某个目录
  · 在线搜索：输入歌名或歌手，回车或点「搜索」。注意接口只给试听直链，
    VIP 或无版权歌曲会提示无法播放，这不是程序故障
  · 双击列表里任意一首开始播放；之后窗口底部会常驻一条迷你播放条
  · 播放区：随机、上一首、播放/暂停、下一首、循环（关→单曲→列表）、停止
  · 歌词时间偏移：单位毫秒，正数让歌词提前出现，负数延后
  · 桌面歌词：悬浮圆角胶囊，可拖动，不抢焦点
  · 任务栏歌词：贴附任务栏上沿的细条，鼠标穿透不挡操作，自动跟随任务栏位置
  · 本地歌曲若在同目录有同名 .lrc 文件会自动加载

六、被控提醒（第 4 页）
  · 「启用被控提醒」后每秒轮询一次
  · 判定方式：匹配到的进程里最大内存 >100MB 判定为被控，<50MB 判定解除，
    中间区间保持原状态（滞回防抖，待机时约 30MB 不会误报）
  · 「进程名 / 路径包含」可填多个关键词，用逗号分隔，默认 uu,gameviewer
  · 「窗口标题包含」作为补充判据，留空则不校验标题
  · 「界面卡顿时也提醒」采样消息循环延迟，捕捉远控造成的异常卡顿
  · 被控期间红色迷你条跟随鼠标循环提醒（显示 2 秒、隐藏 4 秒），解除时单次提示 3 秒
  · 「试弹一次提醒」只验证样式，不影响检测状态
  · 检测为启发式匹配，结果仅供参考

七、竞赛环境（第 5 页）
  · Sublime Text：自动获取官方最新版本号 → 下载 x64 安装包 → 静默安装
  · VS Code：官方 latest 通道下载 User 安装包 → 静默安装
  · Competitive Companion：从 GitHub Releases 取官方扩展包并自动解压（国内直连免 VPN）
      Chrome：地址栏 chrome://extensions → 开右上「开发者模式」→「加载已解压的扩展程序」→ 选解压出的文件夹
      Edge　：地址栏 edge://extensions → 开左下「开发人员模式」→「加载解压缩的扩展」→ 选解压出的文件夹
      （品牌 Chrome 154 起已禁用 --load-extension，只能走这个手动加载流程）
  · MSYS2：从 repo.msys2.org 下载 latest 安装包 → 静默安装到 C:\msys64
  · 一键安装工具链：pacman 装 UCRT64 的 clang、clang-tools-extra(clangd)、gdb、make、gcc，
    并自动把 C:\msys64\ucrt64\bin 加入用户 PATH
  · 装完工具链请重启 Sublime Text，LSP + LSP-clangd 才能找到 clangd
  · 下载会落到「下载」目录；安装日志见 %TEMP%\WindowTool_oi.log

八、通用（第 6 页）
  · 界面主题：浅色 / 深色 / 跟随系统（深色会同步标题栏配色）
  · 强调色：7 种，影响选中态、开关、进度条与滑块
  · 控件圆角：0~20 即时生效，0 为直角
  · 本页还会列出注册失败的全局热键

九、全局热键 (Ctrl+Alt+)
  1  置顶切换            6  取消所有②
  2  置顶+穿透/再按取消    7  图片背景
  3  上移一层            8  视频背景
  4  下移一层            0  取消背景
  5  取消该窗口②         R  随机切换轮播视频
  P  播放 / 暂停         -  / =  当前窗口透明度 -15 / +15

  热键作用于当前聚焦的窗口；焦点在本工具上时作用于列表中选中的窗口。

十、设置保存
  所有设置（主题、强调色、圆角、透明度、显示模式、切换间隔、监控关键词与开关、
  静默、开机启动、音量、歌词偏移、窗口大小、上次停留的页面、背景记忆）
  实时写入 exe 同目录的 settings.txt，重启自动恢复。

十一、注意事项
  · 建议右键「以管理员身份运行」，否则部分高权限窗口无法操作
  · 未签名工具可能被杀软误报，加信任即可
  · 出错不会闪退，会弹提示；详细日志在 %TEMP%\WindowTool_crash.log
  · 关闭程序时会自动还原所有被修改的窗口样式
