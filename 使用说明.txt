【OI 窗口工具】快速上手　v2.0

一、界面
  暗色现代工具风（类 VS Code）：
  · 左侧窄图标导航栏：窗口 / 背景 / 布局 / 设置，图标 + 单行小标题，
    选中项有淡色胶囊和左侧强调色指示条
  · 顶部是常规 − □ × 三个窗口按钮：悬停显示底色，关闭为红色；
    双击标题栏最大化；按住标题栏空白处拖动窗口，四边四角可拉伸
  · 右侧内容区是分组卡片；窗口页左列表右操作，其余页面居中单列
  · 操作结果以顶部滑入的浮动提示条反馈（带语义色指示条），点一下立刻收起
  · 主题在「设置 → 外观」：浅色 / 深色 / 跟随系统；5 种强调色
  · 高分屏（125% / 150% / 200%）原生渲染不模糊

二、启动与退出
  双击 WindowTool.exe 直接显示主界面。
  · 「设置 → 启动 → 静默启动」勾选后，以后双击只在右下角托盘出现图标
  · 「开机自动运行」= 随 Windows 登录自动运行（写入当前用户注册表 Run 项）
  · 单击托盘图标 = 打开主界面；右键托盘图标弹出暗色菜单：
    显示主界面 / 已置顶列表（点谁取消谁）/ 桌面背景 / 深色模式 / 置顶守护 / 退出
  · 点窗口的 × 只是隐藏到托盘，所有功能继续生效
  · 托盘菜单「退出」才会彻底关闭，并自动还原所有被修改的窗口

三、窗口管理（第 1 页）
  1. 在列表里点选目标窗口，或按「点选窗口」后直接去点目标窗口（Esc 取消）
  2. 列表上方输入关键词实时过滤：匹配标题、进程名和窗口类名
  3. 每行右侧的小徽标显示当前状态：顶 = 置顶、穿 = 穿透置顶、景 = 有背景、
     拒 = 置顶被拒绝（通常是高权限窗口，需要管理员运行本工具）
  4. 「始终置顶」自带看门狗守护：被任务管理器、腾讯会议这类会自己
     反复置顶的程序压下去时自动顶回来；前台切换的瞬间也会即时补防。
     守护总开关在「设置 → 置顶守护」
  5. 「点击穿透」= 置顶 + 鼠标穿透 + 透明度 245，把窗口当垫底参考层；
     多个穿透窗口时，先开启的始终压在后开启的上面
  6. 「窗口透明度」滑块即时生效，每个窗口独立记忆
  7. 「层级调整」只在同一层级带内上下移动，不会误跨越置顶层
  8. 「下一显示器」把窗口移到下一块屏幕（保持相对位置，最大化的窗口
     移过去仍是最大化），单屏时提示
  9. 「分屏吸附」3×3 面板：点哪格，窗口就吸附到所在显示器的对应区域；
     「还原吸附」退回吸附前的位置和大小
  10.「毛玻璃」给目标窗口叠亚克力 / 模糊，Win11 效果最好，
     部分窗口或系统无变化属正常，自动降级为普通模糊
  11.「还原全部穿透置顶」一次性取消本工具做过的全部穿透操作

四、窗口背景（第 2 页）
  · 选择图片 → 目标窗口变半透明，背景图窗口紧贴其下方实时跟随移动
  · 显示模式：
      填充裁剪 = 等比放大铺满窗口，居中裁掉超出部分（推荐，无黑边不变形）
      完整显示 = 等比缩放到完全可见，不足处显示黑边
      变形铺满 = 强行拉伸到窗口大小（可能变形）
  · 背景态透明度：数值越低越能看清被背景挡住的窗口内容
  · 「记住各窗口背景」：关闭程序时记住哪些窗口用了什么背景；
    下次启动后出现同名进程且同标题的窗口，会自动恢复（约 2 分钟内）
  · 「当前生效的背景」列出所有挂着背景的窗口，可逐个移除

五、布局方案（第 3 页）
  · 把桌面窗口摆成你想要的样子，输入方案名，点「保存当前布局」
  · 记录内容：每个可见顶层窗口的位置、大小、是否置顶、透明度
  · 点「套用」一键回到那套摆位；窗口句柄每次开机都会变，所以方案按
    「进程名 + 标题」重新找窗口：程序还开着、标题没变，就能套回去
  · 抓取时跳过最小化的窗口；套用时自动还原被最小化的窗口
  · 每个方案最多记录 40 个窗口

六、设置（第 4 页）
  · 主题：浅色 / 深色 / 跟随系统（跟随系统时在 Windows 里切深浅立刻生效）
  · 强调色：石墨蓝 / 青瓷 / 鸢尾紫 / 赤陶 / 苔绿
  · 置顶守护：开关 + 本次运行补回次数统计
  · 自动置顶规则：按进程名添加（点「添加当前目标进程」或手动输入），
    匹配的新窗口一出现就自动置顶 —— 比如加一条 wemeetapp，
    腾讯会议每次打开都自动置顶
  · 开机自动运行 / 静默启动
  · 热键一览表
  · 导出设置 / 导入设置（导入后需重启）/ 恢复默认并重启

七、全局热键 (Ctrl+Alt+)
  1  置顶切换            6  取消全部穿透置顶
  2  穿透置顶/再按取消    7  图片背景
  3  上移一层            0  取消背景
  4  下移一层            N  移到下一显示器
  5  取消该窗口穿透      -  / =  当前窗口透明度 -15 / +15

  另有一组 Ctrl+Alt+Shift + …（分屏吸附，刻意加 Shift 避免撞键）
    ← → ↑ ↓   左 / 右 / 上 / 下半屏
    Q W E R   四个象限
    M 铺满    B 还原到吸附前的位置与大小

  热键作用于当前聚焦的窗口；焦点在本工具上时作用于列表中选中的窗口。

八、设置保存
  所有设置（主题、强调色、守护开关、自动置顶规则、透明度、显示模式、
  静默、开机启动、窗口大小、上次停留的页面、背景记忆、布局方案）
  实时写入 exe 同目录的 settings.txt，重启自动恢复。

九、注意事项
  · 建议右键「以管理员身份运行」，否则任务管理器等高权限窗口无法置顶
    （置顶被拒时列表会标「拒」徽标，并弹提示）
  · 未签名工具可能被杀软误报，加信任即可
  · 出错不会闪退，会弹提示；详细日志在 %TEMP%\WindowTool_crash.log
  · 关闭程序时会自动还原所有被修改的窗口样式（含毛玻璃）
  · 内存：不加载 WPF；隐藏到托盘时主动把工作集交还系统，
    挂后台时任务管理器里的数字会明显下降

十、v2.0 相比 v1.x 的变化
  · 新增：置顶守护（看门狗 + 前台变化即时补防）、自动置顶规则、
    多显示器移动、置顶被拒检测与提示、窗口状态徽标
  · 重写：整套 UI（暗色现代侧栏布局、常规窗口按钮、虚拟行窗口列表）
  · 删除：音乐（本地播放 / 网易云 / 桌面歌词 / 任务栏歌词）、
    竞赛环境一键部署（Sublime / VS Code / MSYS2 / Competitive Companion）、
    视频背景（含 WPF 依赖，常驻内存因此显著下降）
  · 性能：窗口枚举移到后台线程，界面不再被挂死窗口卡住；
    图标与进程名缓存有界，长时间挂机不膨胀
