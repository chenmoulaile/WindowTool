【窗口置顶助手】快速上手

一、启动
  双击 WindowTool.exe 默认直接显示主界面。
  · 单实例：程序已在后台时再次双击 exe，只会把已有主界面拉到前台，
    始终只有一个进程在运行
  · 勾选「静默」后，以后双击将只在右下角托盘出现图标(不弹窗口)
  · 勾选「开机启动」= 随 Windows 登录自动运行(写入当前用户注册表 Run 项)
  · 左键单击托盘图标 = 打开主界面
  · 右键托盘图标 = 只弹小菜单(显示主界面 / 选择图片背景 / 选择视频背景 /
    取消背景 / 退出)，不会弹出主界面；菜单选背景作用于当前聚焦或已选窗口
  · 托盘右键「退出」= 彻底关闭
  · 点主界面右上角 × 只是隐藏，不影响正在生效的功能

二、设置自动保存
  视频背景透明度、定时切换分钟数、显示模式、圆角度、暗色主题、
  UU监控关键词/开关、静默、记住背景开关，
  修改后立即写入 exe 旁的 settings.txt，重启自动恢复。

三、窗口操作
  1. 在下拉框选目标窗口，或点「点选窗口」后直接去点击目标窗口(Esc取消)
  2. 各按钮即时生效；也可以不选窗口，直接在目标窗口上按全局热键
  3. ①「仅置顶」和②「穿透置顶」都是开关式：第1次开启，第2次取消……
  4. 透明度滑块：每个窗口独立记忆，切换选中窗口时滑块自动跟随该窗口的值
  5. 毛玻璃 开/关：给窗口加亚克力/模糊美化效果（Win10 效果最佳，部分
      Win11 版本或个别窗口可能无效，会自动降级为普通模糊）
  6. 圆角: 调节界面控件圆角大小(0~20)，即时生效；按钮/分组卡片为
     抗锯齿平滑圆角，大圆角不再有锯齿毛边(Win11 下主窗口由系统绘制圆角)
  7. 暗色: 勾选切换 GitHub 风格深色主题，标题栏同步变暗

四、背景记忆
  勾选「记住各窗口背景」后，关闭程序时会记住哪些窗口用了图片/视频背景
  (含各自的透明度与显示模式)；下次启动后若出现同名进程且同标题的窗口，
  会在约2分钟内自动检测并恢复其背景。取消勾选则不再记忆。

五、全局热键 (Ctrl+Alt+)
  1  置顶切换            6  取消所有②
  2  置顶+穿透/再按取消   7  图片背景
  3  上移一层            8  视频背景
  4  下移一层            0  取消背景
  5  取消该窗口②         R  随机切换轮播视频
  ← / →  当前窗口透明度 -15 / +15

六、视频背景
  · 「应用视频背景」：选一个视频，自动无限循环播放
  · 「选择文件夹轮播」：选文件夹加载全部视频(mp4/wmv/avi/mkv/mov/m4v)
    之后可用 Ctrl+Alt+R 手动随机切换，或在数字框填分钟数定时自动切换
  · 显示模式下拉框：
      填充裁剪 = 等比放大铺满窗口，居中裁掉超出部分(推荐，无黑边不变形)
      完整显示 = 等比缩放到完全可见，不足处显示黑边
      变形铺满 = 强行拉伸到窗口大小(可能变形)
  · 被控提醒弹窗：白色小条跟随鼠标，1.5秒后自动消失，不挡鼠标操作

七、注意事项
  · 建议右键「以管理员身份运行」，否则部分高权限窗口无法操作
  · 未签名工具可能被杀软误报，加信任即可
  · 出错不会闪退，会弹提示；详细日志在 %TEMP%\WindowTool_crash.log
  · 关闭程序时会自动还原所有被修改的窗口样式(含毛玻璃效果)
