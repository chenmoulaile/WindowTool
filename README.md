# 窗口置顶助手 (WindowTool)

绿色单文件的 Windows 桌面小工具：窗口置顶、鼠标穿透、透明度、图层调整、图片/视频背景、UU远程被控提醒。无需安装任何运行库，双击即用（依赖系统自带的 .NET Framework 4.x）。

## 功能一览

| # | 功能 | 说明 |
|---|------|------|
| ① | 仅置顶 | 让任意窗口始终在最前 |
| ② | 置顶+穿透+透明245 | 点击穿透到下层；多个②窗口时**先应用的始终在最上** |
| ③ | 图层调整 | 上移/下移一层（同层级内移动，不会误跨置顶层）、移到最底 |
| ④ | 透明度 | 每个窗口独立调节 (40~255) |
| ⑤⑥ | 取消② | 单个还原 / 全部还原，自动恢复原始样式 |
| ⑦ | 图片背景 | 目标窗口半透明 + 背景图窗口紧贴其下方实时跟随 |
| ⑧ | 视频背景 | 无限循环播放；支持文件夹轮播 + 随机热键 + 定时切换；三种显示模式(填充裁剪/完整显示/变形铺满) |
| ⑨ | UU远程被控提醒 | 多信号检测：关键词进程的可见会话窗口 / 窗口标题关键词 / 可选"卡顿也提醒"；命中后红色提示条跟随鼠标循环提醒 |

## 全局热键 (Ctrl+Alt+)

```
1  置顶切换        5  取消该窗口②      R  随机切换轮播视频
2  置顶+穿透       6  取消所有②        ←  透明度 -15
3  上移一层        7  图片背景          →  透明度 +15
4  下移一层        8  视频背景
                   0  取消背景
```

热键作用于当前聚焦的窗口；焦点在本工具上时作用于下拉框选中的窗口。

## 使用

直接运行 `WindowTool.exe`：
- 默认启动后显示主界面，右上角「静默」勾选后下次启动将只驻留托盘（左键单击托盘图标打开主界面）
- **单实例**：重复双击 exe 不会出现多个后台，而是把已运行实例的主界面拉到前台
- **托盘菜单**：左键单击图标 = 打开主界面；右键只弹小菜单（显示主界面 / 选择图片背景 / 选择视频背景 / 取消背景 / 退出），不会再误弹主界面
- **暗色主题**：勾选右上角「暗色」即可切换到 GitHub Dark 配色（标题栏同步变暗），按钮悬停为蓝色高亮，设置自动保存
- **退出自动还原**：彻底退出时自动取消所有置顶/穿透(②)/透明度/背景修改，窗口恢复原状
- 托盘右键菜单可退出
- **设置自动保存**：视频背景透明度、定时切换分钟数、显示模式、UU监控关键词与开关、静默启动、暗色主题、圆角度都会保存到 exe 旁的 `settings.txt`，下次启动自动恢复

详细说明见 [使用说明.txt](使用说明.txt)。

## 从源码构建

不需要安装任何 SDK，Windows 自带的编译器即可：

```bat
build.bat
```

- 编译器：`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe` (.NET Framework 4.x)
- 视频功能引用系统自带 WPF 程序集（PresentationCore 等）
- `gen_icon.ps1` 用于重新生成应用图标 app.ico（可选）

## 目录结构

```
WindowTool/
├─ WindowTool.exe     可执行文件（可直接使用）
├─ build.bat          一键编译脚本
├─ gen_icon.ps1       图标生成脚本
├─ app.ico            应用图标
├─ 使用说明.txt        快速上手文档
└─ src/
   ├─ Program.cs      入口 + 全局异常兜底/崩溃日志
   ├─ MainForm.cs     主界面 + 托盘 + 热键
   ├─ Manager.cs      Win32 窗口状态管理（置顶/穿透/图层/透明度）
   ├─ BgWindow.cs     背景窗体（图片绘制 + WPF MediaElement 视频）
   ├─ Native.cs       Win32 API 封装
   ├─ MouseCapture.cs 低级鼠标钩子（点选窗口）
   ├─ UuMonitor.cs    UU远程被控检测
   └─ AlertForm.cs    "你已被控制"提示窗
```

## 常见问题

- **部分窗口操作无效？** 右键以管理员身份运行。
- **杀软报毒？** 工具未签名且会修改其他窗口样式，属误报，加信任即可。
- **Ctrl+Alt+方向键没反应？** 可能被显卡驱动(如Intel屏幕旋转)占用，界面底部绿字会显示注册失败的按键。
- **崩溃了？** 新版有全局异常兜底不会闪退；如遇问题请把 `%TEMP%\WindowTool_crash.log` 内容附在 issue 里。
