## v2.0 重构说明

v2.0 是一次「做减法」的整版重构，聚焦窗口管理这一件核心的事：

- **删除**：音乐播放（本地曲库 / 网易云 / 桌面歌词 / 任务栏歌词）、竞赛环境一键部署（Sublime / VS Code / MSYS2）、视频背景与随之而来的全部 WPF 依赖。
- **新增**：置顶守护（看门狗 + 前台变化即时补防）、自动置顶规则、多显示器一键移动。
- **重写**：整套 UI 换成暗色现代侧栏布局（类 VS Code），常规 − □ × 窗口按钮，不再模仿 macOS 红绿灯。
- **性能**：窗口枚举移到后台线程、常驻内存显著下降（不再加载 WPF）、托盘隐藏后主动归还工作集。

### v2.0.1 修复

- **修复 v2.0 启动即闪退**：自绘控件在构造函数中先改尺寸后建子控件，设 Height 会同步触发 OnResize，导致启动阶段访问未创建控件抛 NullReferenceException，进程闪现即退（无窗口、无进程）。同类问题共清理 5 处（输入框、规则行、方案行、背景行、设置页布局），并全部加上空引用守卫。
- 修复后在虚拟环境实测：主窗体完整给制，消息循环、托盘、全局热键、置顶守护钩子、各定时器均正常运转。

## 简介

OI 窗口工具是一款完全本机的桌面工具，只管一件事：**窗口**。

- **置顶守护** — 让任意窗口始终在最前。被任务管理器、会自己反复置顶的程序（如腾讯会议的某些悬浮窗）压下去时，看门狗会自动把它顶回来；前台切换瞬间即时补防，无需等轮询。对高权限窗口无效时会明确提示「请以管理员身份运行」。
- **点击穿透** — 置顶 + 鼠标穿透 + 半透明（透明 245），把窗口当「垫底参考层」用；多个穿透窗口先开启的始终在最上。
- **图片背景** — 目标窗口半透明化，背景图紧贴其下方实时跟随移动；三种显示模式、背景态透明度、记住各窗口背景。
- **分屏吸附** — 3×3 网格一键吸附到所在显示器工作区，Ctrl+Alt+Shift + 方向 / QWER / M / B。
- **布局方案** — 把整桌窗口的位置 / 大小 / 置顶 / 透明度存成命名方案，一键切回。
- **自动置顶规则** — 按进程名配置（例如 `wemeetapp`），匹配的窗口一出现就自动置顶。

- **免费** — 无付费，无订阅，开源
- **绿色** — 单文件 exe，依赖系统自带 .NET Framework 4.x
- **本地** — 不联网，不收集任何数据

## 界面

暗色现代工具风（类 VS Code / Discord）：

- **布局**：左侧窄图标导航栏（图标 + 单行小标题，选中项淡色胶囊 + 强调色指示条），顶部常规 − □ × 按钮（悬停变色、关闭为红色，双击标题栏最大化），右侧内容区分组卡片。
- **配色**：暗色为默认档（外壳 `#121317` / 导航 `#17181D` / 卡片 `#1E1F25` / 描边 `#33353D`），另有浅色档与跟随系统档；5 个强调色（石墨蓝 / 青瓷 / 鸢尾紫 / 赤陶 / 苔绿）。
- **分层靠 1px 发丝描边**，全站零阴影；语义色（成功 / 警告 / 危险）只用于状态。
- 窗口列表为**虚拟行**绘制（不创建每行控件），几百个窗口也不卡；行内右侧用小徽标标出置顶 / 穿透 / 背景 / 被拒绝状态。
- 高分屏 DPI 原生感知；无边框窗口四边四角可拉伸。

| 页面 | 内容 |
|------|------|
| **窗口** | 可搜索的窗口列表（进程图标 + 状态徽标）、点选窗口、置顶（守护内建）、点击穿透、透明度、层级调整、3×3 分屏吸附、多显示器移动、毛玻璃 |
| **背景** | 图片背景、三种显示模式、背景态透明度、当前生效背景列表、背景记忆 |
| **布局** | 抓取整桌窗口存成命名方案、一键套用 / 删除 |
| **设置** | 主题 / 强调色、置顶守护开关与统计、自动置顶规则、开机自启、静默启动、热键一览、设置导出 / 导入 / 重置 |

## 全局热键 (Ctrl+Alt+)

```
 1  置顶切换              6  取消全部穿透置顶
 2  穿透置顶/再按取消      7  图片背景
 3  上移一层              0  取消背景
 4  下移一层              N  移到下一显示器
 5  取消该窗口穿透        - / =  透明度 -15 / +15
```

另有一组 **Ctrl+Alt+Shift + …**（分屏吸附，刻意加 Shift 以免与上面这组和显卡驱动撞键）：

```
 ← → ↑ ↓   左 / 右 / 上 / 下半屏
 Q W E R   四个象限
 M 铺满    B 还原到吸附前的位置与大小
```

热键作用于当前聚焦的窗口；焦点在本工具上时作用于列表中选中的窗口。

## 性能

- **启动后不加载 WPF**：v2.0 移除视频背景后不再引用 PresentationCore / WindowsBase 等程序集，常驻内存明显下降。
- **窗口枚举在后台线程**：挂死窗口取不到标题也不会冻结界面；标题与类名没变的条目直接复用，图标按进程缓存（有界，32px 缩放后存储）。
- **托盘常驻零负担**：隐藏到托盘时主动 `SetProcessWorkingSetSize(-1,-1)` 归还工作集；守护定时器 1.2s 一拍，加上前台变化事件即时补防，平时几乎零 CPU。

## 构建

```bat
build.bat
```

- 编译器：`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`（只支持 C# 5 语法）
- 引用：System / System.Core / System.Drawing / System.Windows.Forms（无 WPF）

## 注意事项

- 建议右键「以管理员身份运行」，否则任务管理器等高权限窗口无法置顶（置顶失败时程序会明确提示）。
- 未签名工具可能被杀软误报，加信任即可。
- 出错不会闪退，会弹提示；详细日志在 `%TEMP%\WindowTool_crash.log`。
- 关闭程序时会自动还原所有被修改的窗口（置顶 / 穿透 / 透明度 / 背景 / 毛玻璃）。
