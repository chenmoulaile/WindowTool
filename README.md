免费、绿色的 Windows 桌面窗口管理小工具。单文件、无需安装任何运行库，双击即用。

## 简介

窗口置顶助手 是一款完全本地的桌面工具，无需注册、无需联网、不上传任何数据。让任意窗口置顶、点击穿透、调节图层与透明度，还能给窗口垫上图片/视频背景，并在被远程控制时第一时间提醒你。

- **免费** — 无付费，无订阅，开源
- **绿色** — 单文件 exe，依赖系统自带 .NET Framework 4.x
- **本地** — 所有功能在本机完成，不联网、不上传
- **实时** — 背景窗口 60ms 跟随目标窗口移动，被控提醒秒级响应

## 功能一览

| # | 功能 | 说明 |
|---|------|------|
| ① | 仅置顶 | 让任意窗口始终在最前 |
| ② | 置顶+穿透+透明245 | 点击穿透到下层；多个②窗口时**先应用的始终在最上** |
| ③ | 图层调整 | 上移/下移一层（同层级内移动，不会误跨置顶层）、移到最底 |
| ④ | 透明度 | 每个窗口独立记忆调节 (40~255) |
| ⑤⑥ | 取消② | 单个还原 / 全部还原，自动恢复原始样式 |
| ⑦ | 图片背景 | 目标窗口半透明 + 背景图窗口紧贴其下方实时跟随 |
| ⑧ | 视频背景 | 无限循环播放；文件夹轮播 + 随机热键 + 定时切换(分/秒)；三种显示模式 |
| ⑨ | UU远程被控提醒 | **内存判定**：UU进程 >100MB=被控、<50MB=解除；被控时红色迷你条跟随鼠标循环提醒，解除时弹「已解除控制」 |

其他：单实例（重复双击唤醒已运行实例）、托盘右键菜单（可选图片/视频背景）、退出自动还原一切修改、DeepSeek 风格暗色主题、圆角可调、高分屏 DPI 感知。

## 全局热键 (Ctrl+Alt+)

```
1  置顶切换        5  取消该窗口②      R  随机切换轮播视频
2  置顶+穿透       6  取消所有②        ←  透明度 -15
3  上移一层        7  图片背景          →  透明度 +15
4  下移一层        8  视频背景
                   0  取消背景
```

热键作用于当前聚焦的窗口；焦点在本工具上时作用于下拉框选中的窗口。

## 使用

直接运行 `WindowTool.exe`（建议右键以管理员身份运行，否则部分高权限窗口无法操作）：

- 默认启动显示主界面；勾选右上角「**静默**」后下次启动只驻留托盘
- **左键单击托盘图标** = 打开主界面；**右键** = 只弹小菜单（显示主界面 / 选择图片背景 / 选择视频背景 / 取消背景 / 退出）
- **单实例**：程序已在后台时再次双击 exe，会把已有主界面拉到前台
- **暗色**：勾选切换 DeepSeek 风格深色主题（标题栏同步变暗）
- **圆角**：0~20 即时调节，抗锯齿平滑圆角
- **设置自动保存**到 exe 旁的 `settings.txt`，重启自动恢复
- **彻底退出时自动还原**所有修改：取消置顶/穿透、恢复透明度与背景样式

## 开发

不需要安装任何 SDK，Windows 自带编译器即可：

```bat
build.bat
```

> ⚠️ 编译器是 `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`（.NET 4 自带），
> **只支持 C# 5 语法**——新增代码禁止使用字符串插值 `$""`、`?.`、模式匹配等新语法。
> `app.manifest` 提供 DPI 感知与受支持的 OS 声明，勿删。
> `gen_icon.ps1` 用于重新生成应用图标 app.ico（可选）。

## 技术栈

- **UI**: WinForms 全自绘控件（`DarkButton` / `DarkGroupBox` / `DarkSlider`，GDI+ 抗锯齿圆角，DPI 缩放）
- **窗口操作**: Win32 API — `SetWindowPos` / `SetLayeredWindowAttributes` / `RegisterHotKey` / 低级鼠标钩子点选窗口
- **视频背景**: WPF `MediaElement`（`ElementHost` 承载，MediaTimeline 无限循环）
- **系统融合**: DWM API — Win11 系统级窗口圆角、暗色标题栏
- **远控检测**: 进程 WorkingSet 轮询（滞回状态机）+ 窗口标题匹配 + UI 线程卡顿采样
- **持久化**: 零依赖键值文本 `settings.txt`

### 数据流

1. **点选窗口**: 低级鼠标钩子(`MouseCapture`)捕获点击 → `WindowFromPoint` → 根窗口进入下拉列表
2. **置顶/穿透**: `Manager` 修改目标窗口扩展样式（`WS_EX_TOPMOST` / `WS_EX_TRANSPARENT` / `WS_EX_LAYERED`），记录原始样式用于还原
3. **背景跟随**: `BgWindow.Follow()` 以 60ms 定时器读取目标窗口 `GetWindowRect` 并 `SetWindowPos` 紧贴其 Z 序下方；目标关闭自动清理还原
4. **热键分发**: `RegisterHotKey` → `WM_HOTKEY` → 作用于前台窗口或选中窗口
5. **被控检测**: 每秒轮询 UU 相关进程 WorkingSet → 滞回状态机（>100MB 被控 / <50MB 解除）→ `AlertForm` 跟随鼠标循环提醒 / 单次解除提醒
6. **退出还原**: `RestoreAll()` 遍历所有被改窗口，恢复原始透明度、分层样式与置顶状态

### 检测状态机

```
每秒轮询 UU 进程最大 WorkingSet
        │
   >100MB ──→ 被控态：红色迷你条跟随鼠标循环提醒(2s显/4s隐)
        │
   <50MB ───→ 解除：弹「已解除控制」3 秒
        │
  50~100MB ─→ 保持原状态（滞回防抖，待机 ~30MB 不误报）
```

## 常见问题

- **部分窗口操作无效？** 右键以管理员身份运行。
- **杀软报毒？** 工具未签名且会修改其他窗口样式，属误报，加信任即可。
- **Ctrl+Alt+方向键没反应？** 可能被显卡驱动占用，界面底部会显示注册失败的按键。
- **UU提醒没触发？** 确认监控已启用且关键词能匹配到进程（默认 `uu,gameviewer`），状态栏会显示当前检测到的进程与内存。
- **崩溃了？** 有全局异常兜底不会闪退；如遇问题请把 `%TEMP%\WindowTool_crash.log` 内容附在 issue 里。
