免费、绿色的 OIer 桌面工具箱：macOS 风格的窗口管理 + 音乐歌词 + 竞赛环境一键部署。单文件、无需安装任何运行库，双击即用。

## 简介

OI 工具箱 是一款完全本机的桌面工具。它管三件事：**窗口**（置顶、点击穿透、透明度、图层、图片/视频背景）、**音乐**（本地曲库与网易云在线播放、桌面/任务栏歌词）、**竞赛环境**（Sublime Text、VS Code、Competitive Companion、MSYS2 工具链一键装好）。

- **免费** — 无付费，无订阅，开源
- **绿色** — 单文件 exe，依赖系统自带 .NET Framework 4.x
- **本地** — 除音乐搜索与工具下载外不联网，不收集任何数据
- **一键** — OI 环境从零到能写题，下载安装全自动

## 界面

配色与 UI token 在 v1.18 整套重做（旧的苹果系统色板全部删除）：

- **中性阶**：石墨灰阶。亮色底 `#EEF0F3` / 卡片纯白 / 描边 `#C9CDD5`；暗色底 `#141518` / 卡片 `#1D1F24` / 描边 `#3D434E`。暗色是重新调的，不是把亮色反相。
- **分层靠描边，不靠阴影**：卡片、菜单、输入框一律 1px 发丝边 + 明度差，全站零投影。
- **单一强调色**：5 个候选（石墨蓝 / 青瓷 / 鸢尾紫 / 赤陶 / 苔绿），每个都单独验过 WCAG —— 文字与指示条用「文字变体」（对白底 ≥4.5:1），实心块用「填充变体」（对白字 ≥4.5:1）。旧版 7 色里的黄/橙在白字下只有 1.6~2.3:1，属于不可用。
- **语义色**：成功 `#17784F`、警告 `#9A5B00`、危险 `#BE2F28`（暗色各有一组提亮版），只用于状态，不再拿来做装饰。
- 强调色不再出现在导航项上：每个导航项自带彩色的做法删掉了，侧栏只保留一条强调色指示条。
- 控件圆角默认 8、可调 0~16；红绿灯保留 macOS 三色（它是功能标识，不是装饰）。

无边框窗口：红绿灯按钮（悬停显示 × − +）、可拖拽标题带、可缩放边缘、细图标侧栏、分组卡片式设置页。亮色 / 深色 / 跟随系统三档主题（选「跟随系统」时在 Windows 里切深浅会立刻生效，不用重启），高分屏 DPI 原生感知。

图标与动效是这一版重点重做的部分：

- **产品图标**重画为 squircle 底座 + 暖色后层窗口 + 白色前层窗口（带红绿灯与正文行），并按 16/20/24/32/40/48/64/128/256 逐尺寸单独绘制——小尺寸只留高对比轮廓，大尺寸才展开细节，托盘与任务栏不再是被拉伸糊掉的 256 图。
- **图标族**统一画在同一套归一化网格上（等宽描边、圆角端点、一致留白），新增月亮、电源、窗口、网格、闪电等符号；侧栏图标块改为渐变 + 内高光 + 落地投影，有了一点厚度。
- **托盘右键菜单**：25 逻辑像素行高、5 像素内缩、8 像素圆角、9.5pt 菜单字号；分组小标题 + 快捷键 key chip + 勾选列。快捷键做成圆角小标签贴在右侧，不再是一列裸灰字——行高 19 + 裸快捷键正好是 Win32 经典菜单的密度。悬停是「软底 + 左侧强调条」而不是整条实心色块，深色模式单独调过。
- **动画**：帧时钟在动画期间用 `timeBeginPeriod(1)` 把系统时钟精度提到 1ms（Windows 默认 15.6ms，`Sleep(1)` 实际睡 15ms，动画会永远踩在 16/31ms 两档上），补间按墙钟推进、挂在 `Application.Idle` 上。实测真消息循环下帧间隔 **p50 = 16ms、max = 17ms**。
- **切页没有转场动画**，点一下就到位。位图合成层试过（旧页滑走多少新页就滑进多少、240ms、全程不做 alpha 混合），但整页重绘实测 24~29ms/帧，逐帧位移必然掉帧，看起来就是半成品；瞬时切换只花掉一帧，反而干净。保留的是标题带滑动——脏区只有 1760×88 一条，单帧约 1ms。
- **滚动**是短促阻尼跟随：滚轮只推进目标位置，画面按真实时间追上去（tau 45ms，几十毫秒到位）。不做惯性长滑、不做橡皮筋回弹 —— 参考 MyDockFinder 的列表手感，目标明确才有掌控感。
- 侧栏重做为紧凑导航：小号线性图标 + 单行标题 + 选中淡色胶囊 + 左侧彩色指示条（图标块会随胶囊一起滑），去掉了大彩色圆角方块和双行文案。设置页同步收紧：分组标题移到卡片外、卡片去阴影改发丝描边、行高 44/58 → 38/48。
- 「通用 → 界面动画」可整体关闭；默认跟随 Windows 的「在 Windows 中显示动画」设置。

## 内存

常驻后台时刻意压低占用，实测启动后 WPF 完全不加载（`PresentationCore` / `WindowsBase` 不在模块列表里），只有第一次播放音频或启用视频背景才会拉起来。为此做的三件事：

1. `MediaPlayer` 用 `object` 字段持有 —— WPF 类型的**字段**本身就足以让 CLR 在加载宿主类时解析并载入程序集；
2. 所有触到 WPF 类型的语句挪进独立方法 —— JIT 按整个方法体解析，哪怕 `if` 分支永远不进，引用一次也会加载；
3. 250ms 的播放轮询在引擎未启动时直接返回，避免 `Poll()` 被编译。

进程名与窗口图标缓存都有上限并按 FIFO 淘汰（图标统一缩到 32px 存放，原先一张可能是 256px）。隐藏到托盘时主动回收并 `SetProcessWorkingSetSize` 把工作集交还系统。

## 使用

直接运行 `WindowTool.exe`（建议右键以管理员身份运行，否则部分高权限窗口无法操作）：

- 默认启动显示主界面；勾选「静默启动」后下次启动只驻留托盘
- **左键单击托盘图标** = 打开主界面；**右键** = 只弹小菜单（显示主界面 / 图片背景 / 视频背景 / 取消背景 / 逐个还原置顶窗口 / 播放暂停 / 退出）
- **单实例**：程序已在后台时再次双击 exe，会把已有主界面拉到前台
- **点选窗口**：点按钮后直接去点任意窗口即可选中，Esc 取消
- **设置自动保存**到 exe 旁的 `settings.txt`，重启自动恢复（含窗口尺寸与上次停留的页面）
- **彻底退出时自动还原**所有修改：取消置顶/穿透、恢复透明度与背景样式

## 开发

不需要安装任何 SDK，Windows 自带编译器即可：

```bat
build.bat
```

> ⚠️ 编译器是 `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`（.NET 4 自带），
> **只支持 C# 5 语法**——禁止字符串插值 `$""`、`?.`、局部函数、模式匹配等新语法。
> `app.manifest` 提供 DPI 感知与受支持的 OS 声明，勿删。
> `gen_icon.ps1` 用于重新生成应用图标 app.ico（可选）。

### UI 层

界面全部自绘，不用任何第三方控件：

- `Theme.cs` — 设计令牌（石墨中性阶 + 5 个已过对比度的强调色、字体、DPI 缩放 `S/P/Sz`）、圆角路径、发丝描边
- `Controls.cs` — `MacButton` / `MacSwitch` / `MacSegmented` / `MacSlider` / `MacCard` / `MacRow` / `MacField` / `MacNumber` / `MacProgress` / `MacSwatches`
- `MacList.cs` — 自绘列表：圆角选中条、进程图标、右侧次要文本、内嵌滚动条、键盘导航
- `ScrollPanel.cs` — 视口 + 画布式滚动容器
- `Shell.cs` — `MacForm` 无边框外壳（红绿灯、WM_NCHITTEST 拖拽与缩放、DWM 圆角与暗色标题栏）、`MacSidebar`、`Page` 卡片堆叠基类
- `Icons.cs` — 30 余个线性矢量图标，风格对齐 SF Symbols，无需图片资源
- `Toast.cs` — 顶部滑入的浮动提示条

### 离屏核对界面

改完 UI 不必弹窗验证，`dev/RenderHarness.cs` 会把每个页面离屏渲染成 PNG：


## 技术栈

- **UI**: WinForms 全自绘（GDI+ 抗锯齿圆角、矢量图标、DPI 缩放、无边框外壳 + 红绿灯、缓动滚动）
- **窗口操作**: Win32 API — `SetWindowPos` / `SetLayeredWindowAttributes` / `RegisterHotKey` / 低级鼠标钩子点选窗口
- **视频背景**: WPF `MediaElement`（`ElementHost` 承载，MediaTimeline 无限循环）
- **音频播放**: WPF `MediaPlayer`（支持本地文件与 HTTP 直链）
- **系统融合**: DWM API — Win11 窗口圆角、暗色标题栏、亚克力 / 模糊（`SetWindowCompositionAttribute`）
- **窗口摆位**: `MonitorFromWindow` + `GetMonitorInfo` 取工作区，按象限算目标矩形
- **持久化**: 零依赖键值文本 `settings.txt`

### 数据流

1. **点选窗口**: 低级鼠标钩子(`MouseCapture`)捕获点击 → `WindowFromPoint` → 根窗口进入列表
2. **置顶/穿透**: `Manager` 修改目标窗口扩展样式（`WS_EX_TOPMOST` / `WS_EX_TRANSPARENT` / `WS_EX_LAYERED`），记录原始样式与原始透明度用于还原
3. **背景跟随**: `BgWindow.Follow()` 以 60ms 定时器读取目标窗口 `GetWindowRect` 并 `SetWindowPos` 紧贴其 Z 序下方；目标关闭自动清理还原
4. **热键分发**: `RegisterHotKey` → `WM_HOTKEY` → 作用于前台窗口或选中窗口
5. **歌词同步**: 250ms 定时器轮询播放位置 → `Lrc.IndexAt` 二分定位当前行 → 桌面 / 任务栏歌词层刷新
6. **退出还原**: `RestoreAll()` 遍历所有被改窗口，恢复原始透明度、分层样式与置顶状态

## 常见问题

- **部分窗口操作无效？** 右键以管理员身份运行。
- **杀软报毒？** 工具未签名且会修改其他窗口样式，属误报，加信任即可。
- **Ctrl+Alt+方向键/减号没反应？** 可能被显卡驱动或其他软件占用，「通用」页会列出注册失败的按键。
- **网易云某首歌放不出来？** 该接口只提供试听直链，VIP 或无版权歌曲返回空链接，会直接提示无法播放。
- **崩溃了？** 有全局异常兜底不会闪退；如遇问题请把 `%TEMP%\WindowTool_crash.log` 内容附在 issue 里。
